# Mobile Price Viewer

A simple Streamlit-based application for displaying mobile phone products and prices.

## Features
- View mobile phone products
- Show product images
- Display product prices
- Simple user interface with Streamlit

## Technologies Used
- Python
- BeautifulSoup
- Requests
- Streamlit

## How to Run
```bash
pip install -r requirements.txt
streamlit run main.py
